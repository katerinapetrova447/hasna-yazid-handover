Machine Learning Models Library (models.ml)

A pure Java supervised machine learning and dataset preprocessing library built from scratch with zero external ML dependencies. Implements classic classification, regression, text vectorization, and data loading primitives supporting dense arrays, sparse matrices, and direct persistence.

Algorithms & Model Reference

All classifiers (KNN, NaiveBayes, SVM) inherit from Model.java, sharing common fit(), evaluate(), predictLabels(), predictProbabilities(), save(), and load() interfaces.

  • 1. K-Nearest Neighbors (KNN)
    • Metrics Supported: Euclidean, Manhattan, Minkowski, Cosine
    • Features: Supports both dense (double[][]) and sparse (List<Map<Integer, Double>>) inputs, majority voting, and neighbor-distance inspection.
  • 2. Support Vector Machine (SVM)
    • Kernels: Linear, Polynomial, and Radial Basis Function (RBF).
    • Training: Simplified dual coordinate-ascent optimization with hinge loss framing.
  • 3. Naive Bayes
    • Variants: Gaussian (dense only), Multinomial (dense/sparse with Laplace smoothing), and Bernoulli.
    • Computation: Conducted in log-space to prevent numerical underflow.
  • 4. Linear Regression
    • Solvers: Closed-form Normal Equation via Gauss-Jordan matrix inversion or Batch Gradient Descent.
    • Metrics: Evaluated via Mean Squared Error (MSE) and RÂ² score.
  • 5. Logistic Regression
    • Modes: Binary (sigmoid), Multinomial (softmax / one-vs-all), and Ordinal (cumulative logit / proportional odds).

Data Ingestion & Preprocessing

DatasetLoader Protocols

  • CSV / TSV / TXT: Quote-aware (RFC 4180 style) with automatic delimiter detection across sampled lines.
  • JSON: Hand-parsed array of flat key-value objects.
  • SQLite: Connects via JDBC (jdbc:sqlite:) and auto-discovers the primary table schema.

Splitting Strategies (DatasetSplit)

Specified via loader.split(percentage, strategy):

  • Stratified ("stratified" / "s"): Preserves proportional class distribution across splits.
  • Time-series ("timeseries" / "t"): Sequential split without shuffling.
  • Random ("random" / "r"): Random shuffle prior to splitting.

Text & Scaling Utilities

  • StandardScaler: Z-score feature normalization.
  • Text Processing: BagOfWords, TFIDF, cumulative NgramGenerator, WordToVec, and DocToVec.

Quick Start Example

import models.ml.*;
import models.ml.DatasetHandler.*;
import models.ml.DatasetHandler.helpers.DatasetConfig;
import models.ml.KNN.KNN;
import java.util.Map;
import java.util.Arrays;

public class QuickStart {
    public static void main(String[] args) throws Exception {
        // 1. Ingest dataset with configuration
        DatasetLoader dl = new DatasetLoader(
            "Datasets/Iris.csv", 
            DatasetConfig.HAS_ID_WITH_HEADER, 
            "Species"
        );

        // 2. Instantiate model and fit using a 70/30 stratified split
        KNN knn = new KNN();
        knn.fit(dl, 70, "stratified");

        // 3. Evaluate against metrics
        Map<String, Double> metrics = knn.evaluate(new String[] { "accuracy", "precision", "recall" });
        System.out.println("Model Metrics: " + metrics);

        // 4. Generate predictions
        int[] predictions = knn.predictLabels();
        System.out.println("First 5 test predictions: " + Arrays.toString(Arrays.copyOfRange(predictions, 0, 5)));
    }
}

Model Persistence

Models extending Model (KNN, NaiveBayes, SVM) support native JDK binary serialization:

// Save trained model to disk
knn.save("saved_knn_model.bin");

// Restore model from disk
KNN restoredKnn = new KNN();
restoredKnn.load("saved_knn_model.bin");
